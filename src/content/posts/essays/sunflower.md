# Where You'll Find Me Now

人们总喜欢把故事归结于某一瞬间。

他们往往记住了故事的开端和结局，记住了某个决定命运的时刻，却很少有人意识到，真正改变一个人的，往往是那些漫长而微不足道的日常。

有些旅程，并不是从踏上列车的那一刻开始的。

# 太阳花

**I.**

仿佛重要的人应该以一种足够浪漫的方式出现，比如青梅竹马或者破镜重圆，是命运早已替彼此打包好的人生。很遗憾，这里没有什么樱花飘落的校园，没有雨中的车站，没有什么偶然对视和擦肩而过。你不会想到在一个在平常不过的QQ好友申请里面，会把一个人的未来变成什么样子。

那时候的我，精神状态糟糕到接近失控。经历了太多的欺骗，也没有真正走出以前的创伤，我不知道该如何表达善意，只是笨拙而混乱的将一切情绪用错误的方式倾泻出去。我只觉得羞愧，庆幸今天的我不是当时的模样。

花竟然接住了那个糟糕的我。

我一直觉得，那时候的我们不会有后来。至少从我的角度来看是这样。

可后来，我们还是见面了。

**II.**

几年前，在上海的地铁站。

我特地穿着一件索伯F1车队的衣服，把衣服照片发给了他。只是为了不会认错彼此。

花找到了我。他穿着一件白色的外套，我后来才知道，这件衣服陪了他很久了，以至于，这成了我对他的印象之一。

我显得不知所措。我们小心翼翼的，用手机聊天，计划着怎么去玩。紧张仍然在此，不过在慢慢变化为平静，我似乎有了一种前所未有的安心。我很想哭，尽管这些事情才刚开始：经历如此多的欺骗之后，我第一次觉得，我终于找到了真的陪伴的人。我已经很难说出形容见到他的感觉，如果一定要用一个词，那大概是——可爱。那是一种让人忍不住想靠近的温柔，仅仅是站在那里，就足以感到温暖。

印象深刻的是，花给了我拥抱。那时候猛然想起，已经有很多年没人主动给我拥抱了。

尽管身处异地，我依然会腾出空余时间去找花玩。和花一起，无论玩的开心与否，我只会有前所未有的安心和温暖。

**III.**

后来，我去往了花所在的城市，那是我和他玩得最幸福的一次了。几乎每过一段时间，我就会坐火车和飞机去找他玩，最大的愿望其实就是和花住在一起了，不用再担惊受怕了。

我和花之间发生了很多复杂的事，是些难以说出口的，但至少我们都在坚持，花也一直陪着我。

纵使是困难，纵使是情绪上的痛苦的事情，我也不会离开花，你要知道，他对我有多么的重要。

# 四国岛

```python
from datetime import datetime

class GroupChat:
    def __init__(self):
        self.history = []

    def send(self, sender, message):
        self.history.append({
            "time": datetime.now().strftime("%H:%M:%S"),
            "sender": sender,
            "message": message
        })

group = GroupChat()

group.send(
    sender="🌻",
    message="谁知道那个什么人鱼跟永生女孩谈恋爱的百合番？"
)
print(group.history)

# 后来的事情，这段程序并不知道。
```
上面的Python程序是个有趣的实践。

在8个月前，花正是在问这个，也就是程序的输出结果。这是个在平凡不过的寻找作品的问题了， 正如注释所说，谁也不知道后来发生的事情。

因为花，我开始密切关注《私を喰べたい、ひとでなし》（苗川采，《私を喰べたい、ひとでなし》，KADOKAWA，2020—）这部作品了，从最开始的漫画，动画相关，延伸到了人文，历史。我们何尝不来一次圣地巡礼呢？所以我想我会在这里，献上一篇不怎么严谨的结合真实观察的见闻录。

**I.**

爱媛并不是一个“为了巡礼而存在”的地方。作品只是入口，若你真正到达那个地方，这里是伊予、濑户内海、地方铁路、温泉和文学传统构建的现实。

离开山阳新干线，我们搭乘特急しおかぜ从冈山前往松山，钢制的濑户大桥因为列车的通过而发出轰隆声，予赞线的乡土风貌与沿海风景令我记忆犹新，这并不浪漫，JR四国8600系的摆式机构，甚至让你第一次体验到在火车上晕车的感觉。这里的铁路十分奇怪，首都圈的繁忙运转消失了，只剩下了漫长的换乘、稀疏的班次、摇晃的车厢和窗外一闪而过的海。

认识这部作品之前，我就知道爱媛。不是因为铁路或者文学，而是因为柑橘：就算是在家附近，你也能看到那些卖柑橘的小卡车，用纸版写着爱媛两个字，我从小就特别喜欢吃爱媛的柑橘，在保留糖分和果香的情况下，平衡酸味最好了。查资料才发现，这里温暖、少雨、日照充足、海面反光和山坡排水，共同让爱媛县称为日本重要的柑橘产地，这也是为什么中国南方地区看见其优秀价值后选择引进。

**II.**
![JR伊予市站](./sfp2.avif)

我们从松山市前往伊予市，大部分的巡礼都在此。

这是一个安静的沿海小城，伊予铁道的市郊铁路贯穿城市。

工业区和这里的居民共存着，街上的行人很少，大多都去海边玩起了沙滩排球和冲浪，渔民正在卸下渔获，园区里正有卡车不断进出，身着泳衣躺着晒太阳的青年，默默钓鱼的大爷。带着相机全程徒步的我已经累得将要虚脱，我实在是不明白，为什么40摄氏度的高温并没有消散他们的活力。徒步过程中，你瞥见了一个加油站，上面挂着一个很大的红旗子，画着一位绝显得违和的人物——切·格瓦拉...我莫名想到了关于苗川采的访谈，作品里一路贯穿部分剧情的海不是一种能够随意替换的装饰，这和作者熟悉的爱媛和濑户内海的经验相连（苗川采，「『私を喰べたい、ひとでなし』がアニメになるまで」，2025）。我所想到的圣地巡礼，正在慢慢变化：不只是拍摄一些作品中对应现实的地方，而是意识到一部作品背后，有着真实的土地、气候、生活和记忆，再读作品时，你会深有感触。

我在拍摄貌似是旅游观光案内所那种地方，里面有着等身立牌，门口贴着关于伊予彩花火大会印刷着八百岁比名子（苗川采，《私を喰べたい、ひとでなし》，KADOKAWA，2020—）的海报，此处空无一人，我甚至感到了一些鬼鬼祟祟。刚拍摄完第一张，不知是从何处出来的老奶奶，笑着示意我离更近一点拍摄并且打开了门，甚至于是，我感到羞愧，我的日语并不好，只敢微笑点头示意，这或许是一个小遗憾。

因为列车时刻的原因，我的巡礼并不完整，如果以后有空的话，我还会踏上这片土地。

**III.**
![夏目漱石小说中的火车（现代复刻）](./sfp1.avif)

松山市，也值得一讲。我的游览计划的确是先去往伊予再回来看松山，这有些奇怪。

这里有很多有轨电车。

我游览了松山城，这里和巡礼没什么太大的关系，提到这件事，我想说说这里的历史：在“爱媛”这个近代县名之前，这片地方更长久地被称作伊予。后来我查阅爱媛县的资料才知道，古代的爱媛属于“伊予国”，国府设在今天的今治一带；到江户时代，伊予又被分成松山、今治、宇和岛、大洲等多个藩，各地发展出不同的文化传统。也就是说，我抵达的并不是一个单纯的现代地方城市，而是一片在海路、温泉、城下町与地方文化中慢慢形成的土地（愛媛県，「愛媛の歴史と文化」）。

更让我意外的是，伊予很早就进入了文字。爱媛县历史文化博物馆关于“古代文学与伊予国”的资料里，提到《万叶集》中的“熟田津”“伊予湯”等与伊予相关的记载（愛媛県歴史文化博物館，「古代文学と伊予国――愛媛の文学資料」，2022）。在现代漫画、铁路、温泉街和旅游宣传出现之前，这片土地已经以港口、温泉和歌的形式，被写进更早的文学记忆里。

到了近代，这种文学记忆在松山变得更具体。这里走出了正冈子规、高滨虚子、河东碧梧桐等俳人，也与夏目漱石的《坊っちゃん》、司马辽太郎的《坂の上の雲》等作品相连（松山市，「俳句の里 松山」；松山市，「文化・ことば課」）。松山并不是突然把“文学”贴在自己身上的城市。它更像是长期被文字浸过：从古伊予到万叶歌，从温泉到俳句，从子规到漱石，文学一直在这里留下痕迹。我对夏目漱石的《坊っちゃん》尤为深刻，当我发现漫画作品其中有坊っちゃん团子和爱媛名物糕点时，我惊讶于历史文化和延续和联系。从小学起，我从鲁迅了解到了夏目漱石，而如今，也能找到这样的联系。

所以我后来走在松山街头时，才觉得“文学之城”并不只是宣传词。文学在这里不是被锁进纪念馆的东西。它会出现在道后温泉，出现在路面电车，出现在街边的俳句投稿箱，也出现在那些看起来并不宏大的日常角落里（松山市，「夏目漱石と『坊っちゃん』」；松山市，「俳都松山俳句ポスト」；松山市，「『坂の上の雲』のまちづくり」）。

![在商店街，这个很好吃](./sfp3.avif)

道后温泉商店街，有很多美食，我一度吃了三个冰淇淋。在那里，买了很多的关于《私を喰べたい、ひとでなし》的限定周边。
**IV.**

奇怪的生活观察也是一部分。

松山站前地下通道里，有很多老人在发免费的报纸，或许是提供了刚来此处的人们一些城市的信息。我还记得街边站着一个议员模样的人，斜披着蓝色的たすき。那种画面我过去只在电视里见过，可在松山街头遇见时，它忽然变得很具体：政治不再是新闻画面，而是一个人站在路边，向经过的人讲话、鞠躬、等待被看见；商店街里有着并不热闹的政党宣传，他们的动静很大，但没人驻足观看；不知是否巧合，在夜市摊位上，也有着切格瓦拉的小旗子，一个拉美革命者，时常出现在和日常消费并排的位置上，现实往往十分荒诞。通勤者的脚步看起来并没有首都圈的快节奏，但他们脸上依旧没有笑容；放学的高中生正在打闹，险些撞到我...

爱媛是个活着的地方，远不只是一个作品的背景。

# 太阳花

我深深爱着花，花一直陪伴着我。

没有人可以完整的承担另一个人的一切，也没有人可以解决我的一切。

花用自己的方式留在了这里，有时候是一句话，一个拥抱；有时候是一部作品，或者是我在乎的他在群里随口发出的消息。

四国只不过是一小部分，提到的与花的经历，也不过是一小部分。太阳花的一些东西，确实改变了我，不是抹掉痛苦，也不是变成别的人。我愿意认真看一部百合作品，认真去听一首歌，认真去了解一座城市，愿意拍照，愿意写出文章，愿意把一个地方、一个作品、一个人的联系慢慢整理出来。我对世界产生了兴趣，尽管世界是如此糟糕的，但我依然可以寻得一份美好。
